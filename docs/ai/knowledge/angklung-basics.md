# Angklung basics

An angklung is a traditional Indonesian musical instrument made from tuned bamboo tubes mounted in a frame. Each angklung produces a particular pitch when it is shaken, because the bamboo tubes move and resonate.

Angklung is especially suited to ensemble music: each performer may hold one or several pitches, so the group must coordinate rhythm and melody together. This makes the instrument culturally distinctive, collaborative, and visually engaging.

Robotic actuation is interesting because a machine must reproduce the controlled shaking action, coordinate many separate pitches, and preserve musical timing. For visitors and judges: Angklobot combines Indonesian musical heritage with local AI, validated digital arrangements, and motorized note triggering.
